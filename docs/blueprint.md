# **App Name**: RechargeRelay

## Core Features:

- Offer Display: Display the current 'New Year Free Recharge' offer details.
- Referral Link Generation: Generate a unique referral link for the user to share.
- Share Tracking: Track the number of shares made by each user via their referral link. When user reached the threshold (3 shares), then show reward claim button.
- Reward Claiming: Allow users to claim their free recharge upon successfully referring three people.
- Fraud Detection: Implement basic mechanisms to detect fraudulent referral patterns (e.g., multiple accounts from one device) to prevent abuse of the system. This uses a tool to determine when activity may violate the service's TOS.

## Style Guidelines:

- Primary color: Vibrant green (#50C878) to evoke feelings of money and reward, plus it aligns with the implied branding of a telecom.
- Background color: Soft light-green (#E8F4F0), visibly in the green hue family as the primary color but highly desaturated.
- Accent color: Blue (#4682B4), an analogous hue that is less saturated than the primary to set off the primary, without overshadowing.
- Font: 'Inter' (sans-serif) for both headlines and body text, offering a modern, neutral look for clarity and readability.
- Use simple, intuitive icons for sharing and claiming rewards.
- Design a clean and user-friendly layout that guides users through the referral process.
- Incorporate subtle animations when referral milestones are achieved.
